# MediWay

**MediWay** is a React Native mobile app designed to help international students in the Netherlands navigate healthcare using AI.

## Getting Started

### Prerequisites

- Node.js and npm installed  
- React Native CLI  
- Android Studio and/or Xcode (for emulators or device testing)
- Environment file with API-keys (not distributed)

### Installation

#### Android

```bash
cd MediWay
npm install
npx react-native run-android
```

#### iOS

```
cd MediWay
npm install
cd ios
pod install
cd ..
npx react-native run-ios
```
